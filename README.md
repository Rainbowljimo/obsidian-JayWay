# Obsidian Jay-Way (Prototype)

This is a local Obsidian plugin that allows posting content from markdown notes to social platforms via their APIs.

Currently supported:
- Tumblr
- Bluesky

Currently planned:
- Reddit
- Instagram

## Scope
- Local, user-initiated posting only
- No scraping
- No automated engagement
- No scheduled or bulk posting

## Reddit Integration
The Reddit integration uses a "script" application intended for personal use.
Authentication is handled locally, and posts are submitted only when explicitly
triggered by the user from Obsidian.

## Status
This Obsidian is experimental and under active development. It is based on the [Obsidian Sample Plugin](https://github.com/obsidianmd/obsidian-sample-plugin).
**It is not intended for large-scale automation or third-party use.**
